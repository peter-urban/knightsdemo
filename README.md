# knightsdemo
Easy to install demo for knightswhosaydb

https://github.com/benjaminmisiuk/knightswhosaydb/

1) Download repo.
2) install pixi: https://pixi.prefix.dev/latest/installation/
3) run in terminal: pixi run start

Alternative for windows users:

- use the start_notebook.bat

This will use the pixi.exe in the pixi_exe folder
